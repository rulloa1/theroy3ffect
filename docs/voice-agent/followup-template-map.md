# The Roy Effect — Approved Follow-Up Template Map

**Purpose:** The Vapi agent may trigger only the template IDs listed below. Email bodies live in the existing **The Roy Effect Lead Intake Email and Response Playbook** and **The Roy Effect Client Onboarding Questionnaire**. The integration service inserts only allowlisted variables and records every send.

## 1. Allowlisted Template IDs

| Template ID | Trigger | Recipient | Required variables | Source document | Lead-stage action |
| --- | --- | --- | --- | --- | --- |
| `audit_acknowledgement` | A Free Audit request is confirmed. | Lead | `first_name`, `website`, `bottleneck` | Lead Intake Playbook, Template 1 | Set to **Acknowledged** or **Audit in Progress**. |
| `discovery_confirmation` | A discovery call is successfully booked. | Lead | `first_name`, `date`, `time`, `time_zone`, `calendar_link_or_event_reference` | Lead Intake Playbook, Template 6 | Set to **Discovery Scheduled**. |
| `onboarding_questionnaire` | Discovery booking succeeds. | Lead | `first_name`, `date`, `time`, `time_zone`, `questionnaire_url` | Client Onboarding Questionnaire, Section 1 | Keep **Discovery Scheduled**; note questionnaire sent. |
| `human_followup_acknowledgement` | Agent creates a human escalation task and consent exists. | Lead | `first_name`, `followup_method` | Internal approved short acknowledgement | Set to **Human Follow-up Required**. |
| `missed_call_reschedule` | Confirmed discovery call is missed and outreach is approved. | Lead | `first_name`, `calendar_link` | Lead Intake Playbook, Template 13 | Set to **Reschedule Offered** or equivalent. |

## 2. Template Text Sources

### `human_followup_acknowledgement`

**Subject:** Your request has been sent to The Roy Effect

> Hi [First Name],  
> 
> Thanks for reaching out. I’ve shared your request with Rory, who will follow up through [Followup Method].  
> 
> — The Roy Effect

The integration must not add issue details to this acknowledgement. Sensitive information, dispute details, payments, and project-specific information should be handled by a human through an appropriate channel.

## 3. Template Sending Rules

| Rule | Requirement |
| --- | --- |
| Consent | Send only when the caller has confirmed the email address and agreed to receive follow-up, except for transactional appointment confirmation that follows an explicitly requested booking. |
| Sender identity | Send only from the approved The Roy Effect email identity. |
| Dynamic fields | Validate values before insertion; do not accept HTML, arbitrary URLs, attachments, or extra body text from the agent. |
| Deduplication | Do not send the same template more than once per lead action without a human-approved retry. |
| CRM logging | Save template ID, send time, recipient, provider message ID, and outcome. |
| Failure handling | If sending fails, create a human follow-up task; do not loop or expose the failure reason to the caller. |
| Changes | When a template changes, update the source playbook and this map together, version the change, and test in a non-production environment. |

## 4. Variable Definitions

| Variable | Valid source | Validation |
| --- | --- | --- |
| `first_name` | Confirmed caller name | Plain text, length limited. |
| `website` | Confirmed caller URL | Normalize URL; reject non-web protocols. |
| `bottleneck` | Approved audit category | Must match approved enum or a short sanitized value. |
| `date`, `time`, `time_zone` | Calendar booking result | Must be generated by calendar integration, not caller free text. |
| `calendar_link_or_event_reference` | Calendar integration | Use only approved internal booking link or safe event reference. |
| `questionnaire_url` | Server-side configuration | Must be one configured HTTPS questionnaire URL. |
| `followup_method` | Caller-confirmed preference | Email, phone, or either. |
| `calendar_link` | Server-side configuration | Approved scheduling URL only. |

## 5. Agent Speech After Tool Success

| Tool result | Approved spoken confirmation |
| --- | --- |
| Audit acknowledgement sent | “Thanks. Your audit request is logged, and the confirmation is on its way.” |
| Discovery confirmation sent | “You’re booked, and the confirmation has been sent to the email you confirmed.” |
| Questionnaire sent | “I’ve also sent a short questionnaire so Rory can prepare for the call.” |
| Human follow-up acknowledged | “I’ve passed that to Rory and confirmed the best way to reach you.” |
| Send failure | “I’m not able to complete that step right now, but I’ve asked Rory to follow up.” |
